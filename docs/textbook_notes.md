# 교재 ⑤ 정합 메모 (교수용)

교재가 지정한 시뮬레이터(MoveIt2 + RViz **demo 모드**, 4.3)를 그대로
구현했으므로 **교재 3~5·7장 서술이 원문 그대로 성립합니다** — demo 런치
명령(4.4), 마커/Plan/Execute(4.5), 체크포인트 ①~⑦(4.6), OMPL 무작위성(4.7),
plan 확인 후 execute 의 코드 구조(5.1), 그리퍼 세 숫자(5.3), 미션 A 의
토픽·액션·rqt_graph 조사, 7장 시퀀스·Scene 까지 전부 저장소와 일치합니다.

다음 개정 때 참고할 미세 항목만 남습니다.

1. **그리퍼 모델** — 저장소의 그리퍼는 교육용 가상 병렬 2지(폭 0~0.08 m,
   `/joint_states` 에 2관절 추가 → 미션 A ①의 "팔 7 외에 +α" 성립)입니다.
   연구실 실물 그리퍼 모델이 확정되면 2.1절 표의 "정확한 모델·사양은 멘토
   안내" 자리에 명시하고, 저장소 그리퍼 치수·명령 형식을 실물 기준으로
   교체하면 됩니다.
2. **effort 관찰(3장 도전)** — demo 의 effort 는 0으로 채워짐(가상
   컨트롤러). "0인지 비어 있는지 확인" 문항의 정답이 '0'으로 확정 —
   원문 그대로 유효하며, 원하면 힌트로 명시 가능.
3. **모드/에러 상태(3.2·미션 ③)** — demo 에는 해당 토픽이 없어 "없음"
   기록이 정답(교재가 이미 허용). 실기체(rm_driver)에서 등장.
4. **pose 기준점** — 저장소는 손끝(gripper_tcp) 기준으로 구현(마커도
   손끝에 표시). 5.2절 "손끝의 목표 위치·자세" 서술과 정합 — 별도 수정
   불필요, 참고만.
5. **6.4 기본 모션 명령 시연** — MoveJ/L/P 는 제조사 티칭 SW·rm_driver
   경로로 실기체에서만(교재 서술 그대로). demo 미지원이 원문과 일치함을
   확인.
